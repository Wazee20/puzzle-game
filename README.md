# لعبة تركيب الصور

لعبة تركيب صور تعمل في المتصفح، ويمكن تثبيتها كتطبيق ويب (PWA) على Android وiPhone من خلال GitHub Pages.

## اللعب والتثبيت

- افتح الموقع عبر HTTPS: https://wazee20.github.io/puzzle-game/
- على Android: من قائمة Chrome اختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
- على iPhone: افتح الموقع في Safari، واضغط **مشاركة** ثم **إضافة إلى الشاشة الرئيسية**.
- بعد تحميل ملفات اللعبة لأول مرة، يمكن فتحها دون اتصال بالإنترنت.

هذه نسخة ويب قابلة للتثبيت وليست تطبيقًا منشورًا في App Store أو Google Play.
